# teldrive-AutoInstaller
Teldrive Auto Installer
🇧🇷 Português

Teldrive Auto Installer é um instalador automático e inteligente para o projeto Teldrive.

Ele foi criado para permitir que qualquer pessoa, mesmo sem conhecimento técnico, consiga instalar, atualizar e executar o Teldrive em poucos minutos.

O instalador detecta automaticamente dependências, instala componentes necessários e guia o usuário passo a passo.

Recursos

instalação automática do Git

instalação automática do Go

clonagem automática do repositório Teldrive

atualização automática do projeto

detecção de instâncias já rodando

reinstalação mantendo configuração

configuração automática do config.toml

suporte a Ngrok

suporte a Cloudflare Tunnel

execução em modo local ou externo

criação de atalho na área de trabalho

logs detalhados

verificação automática de atualizações

Tudo foi pensado para funcionar em modo guiado para iniciantes.

🇺🇸 English

Teldrive Auto Installer is an automated and intelligent installer for the Teldrive project.

It was designed so that any user, even without technical knowledge, can install, update and run Teldrive within minutes.

The installer automatically detects dependencies, installs required components and guides the user step-by-step.

Features

automatic Git installation

automatic Go installation

automatic Teldrive repository cloning

automatic project updates

detection of running instances

reinstall while keeping configuration

automatic config.toml setup

Ngrok support

Cloudflare Tunnel support

local or external execution

desktop shortcut creation

detailed logs

automatic update check

Everything is designed to work in a beginner friendly guided mode.
